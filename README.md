# VladRoad — туристический навигатор по Владивостоку

Дипломный проект (2026). Веб-сервис, который помогает находить интересные места Владивостока, смотреть готовые маршруты и создавать собственные прогулки по городу.

## Возможности
- Готовые маршруты и интерактивная карта с местами (достопримечательности, кафе, рестораны)
- Создание собственного маршрута на карте: пеший, автомобильный или смешанный
- Регистрация и вход, личный кабинет: свои маршруты и избранное
- Сохранение, переименование и удаление маршрутов
- Панель администратора со статистикой и списком пользователей

## Стек
- Backend: Python, Flask
- База данных: SQLite (работа через модуль sqlite3, SQL-запросы написаны вручную, без ORM)
- Frontend: Jinja2-шаблоны, HTML/CSS/JavaScript, [библиотека карты и сервис построения маршрутов]
- Безопасность: хэширование паролей (Werkzeug), параметризованные SQL-запросы

## База данных
Таблицы: `users`, `routes` (маршруты пользователей, связаны с `users` через `user_id`), `ready_routes` (готовые маршруты), `pois` (места на карте).

## Моя роль
Backend и проектирование базы данных, подключение карты; работа в паре с frontend-разработчиком, согласование интерфейсов, поиск и исправление ошибок на стыке частей.

## Запуск локально
```bash
git clone https://github.com/KseniaShaveko/VladRoad.git
cd VladRoad
pip install -r requirements.txt
python app.py
```
Приложение будет доступно на http://localhost:5000. База данных создаётся автоматически при первом запуске.
